contenteditable (the primitive behind rich-text editors)

Click here and start typing — this whole <div> is editable. Try pasting some bold text from another app to see how "messy" the resulting HTML can get (open DevTools → Elements to inspect it).

Real WYSIWYG editors (Google Docs-style) build heavy sanitization and normalization logic on top of this raw contenteditable primitive — they don't trust its output directly.
