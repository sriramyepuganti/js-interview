Responsive Images + innerHTML vs textContent Safety Demo

Two independent demos on one page: (1) native responsive images with srcset/sizes/<picture>, and (2) why innerHTML is an XSS risk with untrusted input, and why textContent is not. See files 06-performance-and-seo.md and 09-html-topics-you-might-have-missed.md for the full writeups.

1a. Resolution Switching (srcset + sizes)

Open DevTools → Network, filter by "Img", then resize this browser window (or use device toolbar to simulate a phone) and reload. Watch which candidate file the browser actually requests — it picks based on viewport width × device pixel ratio, matched against sizes.

1b. Art Direction (<picture> + media)

This isn't just a smaller version of the same photo — resize the window below ~700px wide and the browser swaps to a completely different, tighter crop meant to work at narrow widths, instead of squeezing the wide shot down into an unreadable sliver.
