Structured Data + ARIA Landmark Roles

Part 1: ARIA Landmark Roles (via semantic tags)

Site Header — logo + site title would go here.
Primary Navigation — Home | Shop | Contact
Main Content — the page's one unique content area (the product card in Part 2 lives here in a real page).
Aside (inside main) — "you might also like" content, tangential to the main content.
Generic labeled region — used when no dedicated landmark tag fits, but the section is still important enough to expose as a jump-to target.
Footer Navigation — Privacy | Terms
Site Footer — © 2026 Demo Store. All rights reserved.

Notice there are two <nav> elements above — each got a distinct aria-label ("Primary" / "Footer") so a screen reader user jumping through landmarks can tell them apart instead of hearing "navigation" twice with no context.
