Click the button below. No page reload, no CSS rebuild — just a runtime variable reassignment.

How this works

All colors here read from var(--bg-color), var(--text-color), etc. Toggling data-theme="dark" on the <html> element re-defines those same variable names inside a [data-theme="dark"] selector — every element using var(...) updates instantly because custom properties are resolved live by the browser, not compiled away like Sass $variables.
