Float — original job (wrap text around a shape)

This paragraph of text wraps around the floated circular image to its left, exactly the way a magazine layout wraps body copy around a photo or pull-quote. This is the original, still-legitimate use of float — nothing about it is legacy or discouraged.

Multi-Column Layout

Reflowing Article Text

This paragraph is long enough to demonstrate multi-column reflow. The browser automatically flows text from the bottom of the first column to the top of the second, the same way a printed newspaper or magazine has always laid out body copy, without any manual splitting into separate elements.

Resize the browser window narrower to see the columns collapse behavior change, and note how the heading above never gets awkwardly split across a column break, thanks to break-inside: avoid.
