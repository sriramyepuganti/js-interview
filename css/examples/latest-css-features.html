1. Cascade Layers (@layer)

This heading uses .text-brand

Look at the CSS: .card h1 is more specific than .text-brand (an element+descendant selector vs. a single class), but it lives in the earlier components layer. .text-brand lives in the later utilities layer, declared after components in @layer reset, base, components, utilities; at the top of the stylesheet -- so it wins the color, proving layer order beats specificity.

This card itself also has a &:hover and &.featured nested rule -- hover over this card to see the border/shadow change (feature 2, native nesting).

2. Native CSS Nesting

This .card block styles itself, its nested h2, its :hover state, and its .featured modifier -- all written directly inside one nested rule in plain CSS, no Sass compiler involved.

3. Scroll-Driven Reveal — Card A

This card fades and slides in as it enters the viewport, driven by animation-timeline: view() and animation-range: entry 0% cover 40%. No IntersectionObserver, no scroll event listener -- the browser computes this animation's progress purely from this element's position relative to the viewport.
